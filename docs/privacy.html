プライバシーポリシー

最終更新日：2026年8月26日

1. 概要

Google Drive Vault Sync（以下「本プラグイン」）は、Obsidian Vaultをユーザー自身のGoogle Driveと同期するオープンソースのコミュニティプラグインです。本プラグインの運営者は同期用サーバーを提供せず、ユーザーのVault内容を収集しません。

2. Googleユーザーデータへのアクセス

本プラグインはGoogle OAuthのdrive.fileスコープを使用し、本プラグインがGoogle Drive上で作成したファイル、またはユーザーが本プラグインに対して明示的に選択したファイルへアクセスします。Googleアカウントのパスワードにはアクセスしません。

3. 利用目的

Googleユーザーデータは、ユーザーが指示したVaultのアップロード、ダウンロード、更新、削除同期、競合検出および復元のためだけに使用します。広告、分析、販売、信用評価その他の目的には使用しません。

4. 保存と暗号化

同期対象の本文は端末上でAES-256-GCMにより暗号化され、ユーザー自身のGoogle Driveへ保存されます。OAuth秘密値、リフレッシュトークンおよびVault鍵は利用端末のObsidian SecretStorageに保存され、運営者のサーバーへ送信されません。

5. 共有と第三者提供

運営者はGoogleユーザーデータを収集、販売、貸与または第三者へ提供しません。Google Driveとの通信はユーザーの端末とGoogleの公式APIとの間で直接行われます。

6. 保持と削除

暗号化された同期データは、ユーザーが削除するまでユーザー自身のGoogle Driveに保持されます。ユーザーはプラグイン内の接続解除、Googleアカウントの第三者アクセス管理、またはGoogle Driveからの削除によってアクセス権や保存データを管理できます。

7. Google API Services User Data Policy

本プラグインによるGoogle APIから受け取った情報の利用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use要件を含む）に従います。

8. お問い合わせ

本ポリシーに関する連絡はGitHub Issuesをご利用ください。認証トークン、クライアントシークレット、Vault鍵などの機密情報は投稿しないでください。

Google Drive Vault Sync is an independent community project.
